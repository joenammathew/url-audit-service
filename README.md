# URL Audit Service

A production-grade URL audit service built for Digital Heroes Software Development Task.

## Live URL
https://url-audit-service.onrender.com

## GitHub Repository
https://github.com/joenammathew/url-audit-service

## Features
- ✅ URL validation with Zod
- ✅ HTTP requests with timeout (10 seconds)
- ✅ HTML parsing with Cheerio
- ✅ Caching with node-cache (5 minute TTL)
- ✅ Rate limiting (100 requests per minute)
- ✅ Error handling for common failures
- ✅ Structured logging
- ✅ Request IDs for tracking
- ✅ Deployed on Render.com
